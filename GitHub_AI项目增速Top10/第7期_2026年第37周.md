### 🥇 第1名：i-have-adhd — ADHD 友好的 Agent 输出技能

| 属性 | 详情 |
|------|------|
| **仓库** | [ayghri/i-have-adhd](https://github.com/ayghri/i-have-adhd) |

| **总 Star** | ⭐ 44,327 |
| **语言** | Python |
| **许可证** | MIT |

**项目简介**：一套 Claude Code 插件/技能，解决编码 Agent 常见痛点——把结论埋在冗长输出里。通过结构化、高信号密度的回复格式，让开发者更快看到「答案在哪」，兼顾 ADHD 友好与日常工程效率。标签覆盖 `claude-skills`、`developer-tools`、`productivity` 等。

**上榜理由**：本周以 **+16,476** 星断层领跑全站周榜，约为第 10 名的 3 倍以上。在 Skills 赛道中，它切中的是「Agent 话太多、重点找不到」这一普遍体验问题，传播极快。

## 📈 本周趋势观察

### 1. 周榜增速进入「万星俱乐部」时代
本周 AI 相关 Top 1（i-have-adhd +16,476）与 Top 2（archify +10,299）均达万星级单周增量，Top 10 门槛升至 **+5,120**（markitdown），较第 6 期 Top 10 底线（+152）数量级跃升。全站流量与 AI 细分赛道同步放大。

### 2. DeepSeek Harness 生态正式接棒叙事
deepseek-harness（+8,842）与 archify（+10,299，DSH 插件）同周高位，标志「Harness = Agent 操作系统、Skills = 插件」的故事线从社区实验进入大厂背书阶段。

### 3. 「Agent 交付体验」Skills 三分天下
i-have-adhd（输出可读性）、ponytail（少写废话代码）、diagram-design / archify（可视化交付）同时霸榜，开发者关注点从「能跑」转向「用起来像资深同事」。

### 4. 多 Agent 编排与本地多模态并进
orca（并行 Agent ADE）与 VoiceStudio（本地语音全栈）分别代表「编排层」与「模态层」两条增长线，Top 10 不再全是纯文本编码助手。

### 5. 落选区仍藏高增速网关与写作技能
第 11–20 名中 OmniRoute（AI 网关）、humanizer（去 AI 味写作技能）、hyperframes（Agent 视频 HTML）增速均超 3800，下周冲榜概率高。
