### 🥇 第1名：ponytail — 「最懒高级工程师」Agent 思维技能

| 属性 | 详情 |
|------|------|
| **仓库** | [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) |
| **本周新增** | ⭐ 450 |
| **总 Star** | ⭐ 64,419 |
| **语言** | JavaScript |
| **许可证** | MIT |

**项目简介**：一套 Claude Code 技能框架，核心理念是让 AI Agent 像「房间里最懒的高级工程师」一样思考——最好的代码是你从未写过的代码。贯彻 YAGNI（You Aren't Gonna Need It）原则，避免过度设计，聚焦最小可行实现。支持 Claude Code 插件、Cursor Rules 等场景。

**上榜理由**：本周以 +450 Star 再度登顶 AI 周榜，连续多周稳居 Top 3。总 Star 已突破 6.4 万，说明「少写代码、少过度设计」的 Agent 工程哲学正在获得广泛共鸣。

### 🥈 第2名：headroom — AI Agent 上下文压缩

| 属性 | 详情 |
|------|------|

| **本周新增** | ⭐ 245 |
| **总 Star** | ⭐ 53,116 |
| **语言** | Python |
| **许可证** | Apache-2.0 |

**项目简介**：面向 AI Agent 的上下文压缩层，在工具输出、日志、文件和 RAG 分块到达 LLM 之前进行压缩，减少 60-95% 的 Token 消耗，同时保持回答质量不变。提供库、代理和 MCP 服务器三种使用方式，支持多种压缩算法，本地优先且可逆。

**上榜理由**：项目已迁移至 headroomlabs-ai 组织，总 Star 突破 5.3 万。作为 Token 成本优化的核心基础设施，本周 +245 Star 稳居第二，持续验证 Agent 落地对「省钱」的刚需。

## 📈 本周趋势观察

### 1. Agent Skills 生态持续主导
本周 Top 10 中有 **5 个项目** 直接属于 Agent Skills 框架或技能库（ponytail、skills、superpowers、taste-skill、hermes-agent），另有 headroom、Agent-Reach、cognee 等 Agent 基础设施项目同台竞技，Skills 已成为 AI 编码 Agent 的核心组织方式。

### 2. Token 优化与记忆基础设施并进
headroom（上下文压缩）和 cognee（Agent 记忆）同时上榜，说明 Agent 落地的两大核心痛点——「省钱」和「记住」——正在形成独立的基础设施赛道。

### 3. Agent 感知能力扩展
Agent-Reach 以 +208 Star 排名第四，Agent 从「只能看本地文件」扩展到「读取全网内容（含 B站、小红书）」，感知层正在快速丰富。

### 4. AI + 垂直场景落地加速
daily_stock_analysis（金融）和 Unlimited-OCR（文档解析）的上榜，表明 AI 项目正从通用工具向垂直行业场景深度渗透。

### 5. 中文 AI 项目表现稳健
Agent-Reach、daily_stock_analysis、Unlimited-OCR 三个项目均与中文开发者社区高度相关，中文 AI 开源生态持续产出高质量项目。
