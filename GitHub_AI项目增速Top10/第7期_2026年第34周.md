## 📈 本周趋势观察

### 1. DeepSeek Harness 生态爆发
本周第一名 deepseek-harness 单周 +7.6 万 Star，断层领先。插件化 Harness 架构 + DeepSeek 官方背书，带动 open-design 等 DSH 生态插件同步增长，形成「框架 + 插件」的新范式。

### 2. Skills 赛道持续霸榜
mattpocock/skills（+12,654）稳居第二，总 Star 超 23 万；落选区的 ui-ux-pro-max-skill 同样高增长。Agent 能力组织方式正从「提示词」全面转向「Skills 技能包」。

### 3. 终端 Agent 三国杀成型
openai/codex（+5,950）、stablyai/orca（+5,066）、earendil-works/pi（+4,552）同时上榜，加上落选区的 opencode，终端 Agent 与 ADE 赛道竞争白热化。

### 4. Agent 基础设施分层成熟
OmniRoute（网关路由 + Token 压缩）与 ponytail（YAGNI 工程思维）代表「省钱」与「提质」两条基础设施线，Agent 落地痛点正在被系统性解决。

### 5. AI 安全成为新热点
usestrix/strix 以 +4,650 Star 闯入 Top 10，AI 渗透测试、LLM 安全、红队自动化等方向获得开发者高度关注，安全与 Agent 的交叉赛道正在成型。
