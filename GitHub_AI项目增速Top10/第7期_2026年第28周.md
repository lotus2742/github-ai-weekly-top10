**项目简介**：一款隐私优先的 AI 会议助手，基于 Rust 构建，支持 Parakeet/Whisper 实时语音转录（号称 4 倍速）、说话人分离（Speaker Diarization）和 Ollama 本地摘要。100% 本地处理，无需云端。支持 macOS 和 Windows，是开源自托管 AI 会议记录工具的代表之作。

## 📈 本周趋势观察

### 1. Claude Code Skills 生态全面爆发
本周 Top 10 中有 **6 个项目** 直接服务于 Claude Code 技能生态（skills、taste-skill、ponytail、codex-plugin-cc、caveman，以及间接相关的 system_prompts_leaks）。Skills 已从「可选增强」演变为 AI 编码工具的核心组织方式。

### 2. Token 优化技能持续走红
caveman（-65% Token）和 ponytail（YAGNI 极简主义）的高增长，说明开发者在 AI 编码场景中对 Token 成本的敏感度仍在上升。与前几周的 headroom（上下文压缩）形成呼应，Token 优化贯穿 Agent 全链路。

### 3. 大厂正式入局 Agent 工具链
OpenAI 发布 codex-plugin-cc（Claude Code 官方插件）、阿里巴巴开源 page-agent（页面 GUI Agent），标志着 AI 巨头从「各自封闭」转向「生态互通」，开源 Agent 基础设施竞争加剧。

### 4. AI 垂直场景工具分化明显
meetily（会议记录）、strix（安全渗透）、firecrawl（网页数据）、page-agent（浏览器操控）分别切入不同垂直场景，AI 开源项目正从「通用 Agent」向「场景专用工具」深度分化。

### 5. 本周增速整体趋缓
本周 Top 1 仅 +87 Star（对比第3期 Odysseus 的 +2,056），Top 10 新增 Star 集中在 64–87 区间，增速明显低于前期爆发周。说明 AI 开源热度进入平稳增长期，竞争更加精细化。
