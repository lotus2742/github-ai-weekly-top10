### 🥇 第1名：deepseek-harness — DeepSeek AI 编程 Harness

| 属性 | 详情 |
|------|------|
| **仓库** | [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness) |
| **本周新增** | ⭐ 19,784 |
| **总 Star** | ⭐ 204,737 |
| **语言** | TypeScript |
| **许可证** | MIT |

**项目简介**：DeepSeek 官方推出的 AI Agent 编程 Harness 框架，核心理念是「Everything is a Plugin」。基于 Cordis 插件系统构建，开发者可通过插件扩展 Agent 能力，将模型、工具、工作流全部模块化。项目定位为 AI 编码 Agent 的「操作系统层」，同一模型在不同 Harness 中表现可相差数个量级。

**上榜理由**：本周以近 2 万新增 Star 断层领跑，创本榜历史最高单周增速记录。DeepSeek 官方背书 + Harness 概念爆发，使其成为本周 GitHub 全站最热门项目。总 Star 已突破 20 万，社区验证极其充分。

## 📈 本周趋势观察

### 1. Harness 概念全面爆发，DeepSeek 官方入场
DeepSeek Harness 以近 2 万新增 Star 创本榜历史记录，将「Harness」从社区概念推向主流。同一模型在不同 Harness 中表现可相差数个量级——这一认知正在重塑开发者对 AI 编码 Agent 的理解。Pi 作为社区 Harness 代表同步进入 Top 10。

### 2. 终端 Agent 三国杀正式开打
OpenAI Codex（+7,747）、Orca（+5,686）、Pi（+3,752）三大终端 Agent 方案同台竞技，加上 Claude Code 生态的 Skills 和免费替代方案 free-claude-code（+4,823），终端 Agent 赛道本周贡献 Top 20 中超过一半的席位。

### 3. Skills 生态仍是基本盘
mattpocock/skills（+10,109）稳居第二，ponytail（+8,294）暴增至第三，andrej-karpathy-skills（+3,566）和 superpowers（+3,420）在落选区同样亮眼。Skills 作为 Agent 能力组织方式的地位不可撼动。

### 4. AI 网关与路由基建崛起
OmniRoute（+4,977）和 free-claude-code（+4,823）的高增长，反映出开发者在模型碎片化、订阅成本高企的背景下，对「统一接入 + 成本优化」基础设施的迫切需求。

### 5. 增速量级跃升，市场进入新阶段
本周 Top 1 新增 19,784 Star，较第6期 Top 1 的 414 暴涨约 48 倍；Top 10 门槛从 +152 跃升至 +3,752。AI 开源项目正从「小众极客圈」进入「大众开发者」阶段，star-history 周榜的竞争烈度显著提升。
