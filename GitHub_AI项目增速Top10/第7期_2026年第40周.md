## 📈 本周趋势观察

### 1. 周增速整体「跳档」
第 6 期 Top 1 为 headroom（+414），本周 VoiceStudio 达 +15,134，全站 Top 10 门槛升至约 +4,776。并非单一项目偶然爆发，而是语音、记忆、Harness、运行时等多条线同时放量。

### 2. 本地语音 AI 成为新龙头赛道
VoiceStudio 以「全本地 ElevenLabs 替代」定位夺冠，覆盖克隆、配音、转写、有声书等完整工作流。云端语音 API 成本与数据出境顾虑，推动开发者转向可自托管方案。

### 3. Agent 记忆与编排「上下半场」
hindsight（记忆学习）与 paperclip、orca（职场/舰队编排）包揽第 2、3、7 名，显示 Agent 竞争焦点从「模型智商」转向「记得住、管得住、能并行」。

### 4. 官方与大厂 Harness 生态加速
deepseek-harness（DeepSeek 官方）、OpenShell（NVIDIA 运行时）本周均 +5k 量级；社区插件（如 archify，见落选榜）同步走高，插件化 Agent 底座成为默认架构想象。

### 5. Skills 与工程教育仍是基本盘
ponytail、mattpocock/skills、ECC 合计周增超 1.7 万星；ai-engineering-from-scratch 进 Top 10，表明「技能包 + 系统学习」仍是开发者入场 Agent 时代的主路径。
