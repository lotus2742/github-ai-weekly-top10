## 📈 本周趋势观察

### 1. 周榜增速大幅回落，GitHub Star 数据受限影响显著
本周 Top 1 仅 +48 Star，较第6期 Top 1 的 +414 下降约 88%。star-history.com 已标注 GitHub 限制 Star 数据访问，周榜数字整体进入「低增速新常态」，排名相对关系仍具参考价值，但绝对数值不宜与历史期直接对比。

### 2. AI 网关与模型路由层崛起
OmniRoute（+44，第2名）作为一站式 AI 网关强势进榜，290+ 提供商、Token 压缩、MCP/A2A 支持一应俱全。多模型混用时代，「路由层」正在成为 Agent 基础设施的新热点。

### 3. 并行 Agent 编排进入产品化阶段
orca（ADE 并行 Agent 环境）与 herdr（终端 Agent 多路复用器，落选第14名）同时活跃，说明开发者已从「单 Agent 对话」迈向「Agent 舰队」管理，终端 UI 重新成为 Agent 开发的主战场。

### 4. 代码知识图谱赛道持续升温
graphify（第7名）与 code-review-graph（第10名）双双上榜，加上落选的 ECC（第19名），「让 AI 读懂代码库」的知识图谱方案已形成竞争格局，本地 AST 解析 + 可解释边成为共同技术选型。

### 5. 语音 AI 与 OCR 等垂直能力获关注
Unlimited-OCR（百度，第6名）和落选的 voicebox（语音克隆）、moonshine（低延迟 STT/TTS）表明，在 Agent 基础设施之外，文档理解与语音交互等垂直 AI 能力仍在稳步积累开发者兴趣。
