## 📈 本周趋势观察

### 1. Harness 概念全面爆发
deepseek-harness（官方框架）+ archify（DSH 插件）+ ECC（Harness 原生优化）本周集体高增长，「Harness = Agent 的操作系统层」正在成为行业共识。DeepSeek 官方入场更是将这一概念推向主流。

### 2. 增速创历史新高，市场进入「超级周期」
本周 Top 1 archify 单周 +17,983 Star，较第6期 Top 1 的 +414 暴涨约 43 倍。Top 10 门槛从 +152 跃升至 +4,869，说明 AI 开源社区正经历一轮前所未有的关注爆发。

### 3. Skills 生态仍是基本盘
Top 10 中有 **6 个项目** 直接属于 Agent Skills 范畴（archify、skills、ponytail、scientific-agent-skills、humanizer，以及 Harness 插件生态），Skills 作为 Agent 能力组织方式的地位不可撼动。

### 4. 终端 Agent 三国杀格局成型
orca（并行舰队 ADE）、deepseek-harness（插件化 Harness）、以及 Pi 等终端 Agent 工具本周均高速增长，开发者正在为多 Agent 并行协作选择基础设施。

### 5. 垂直场景 AI 工具崛起
OpenMAIC（教育）、VoiceStudio（语音）、scientific-agent-skills（科研）三个垂直领域项目同时进榜，说明 AI 开源生态正从「通用工具」向「场景深耕」演进。
