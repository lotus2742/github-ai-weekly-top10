## 📈 本周趋势观察

### 1. Skills 生态仍是绝对主旋律
本周 Top 10 中有 **5 个项目** 直接属于 Skills/Agent 技能范畴（skills、superpowers、ponytail、graphify、ECC），另有 orca、pi、QwenPaw 等 Agent 基础设施项目。**Skills 作为 Agent 能力组织方式的地位不可撼动**，增速放缓但统治力不减。

### 2. 并行 Agent 编排成为新热点
orca（并行 Agent 舰队 ADE）和 herdr（编码 Agent 运行时）的崛起，标志着开发者从「单 Agent 对话」迈向「多 Agent 并行协作」。专用 ADE 和 Agent Runtime 正在成为 Agent 生态的新一层基础设施。

### 3. AI 网关与模型路由需求爆发
OmniRoute 首次进榜，一个端点接入 290+ 提供商、500+ 模型，与 Token 压缩能力结合。模型提供商碎片化加剧，「统一网关 + 智能路由 + 成本优化」成为刚需。

### 4. 增速持续探底，市场进入稳态
本周 AI 周榜 Top 1 仅 +39 Star，Top 10 门槛降至 +14，较第3期 Top 1 的 +2,056 下降约 98%。市场从爆发期进入稳态增长，但 Top 10 项目总 Star 均值仍超 10 万，说明头部项目社区基本盘健康。

### 5. 国内 AI 开源力量持续出海
QwenPaw（阿里 AgentScope）首次进入 Top 5，alibaba/open-code-review 进入落选名单。国内大厂在 Agent 基础设施和代码审查 Agent 赛道的开源布局开始获得国际社区认可。
