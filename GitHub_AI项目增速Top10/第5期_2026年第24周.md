## 📈 本周趋势观察

### 1. Skills 赛道全面爆发
本周 Top 10 中有 **6 个项目** 直接属于 Skills 范畴（last30days-skill、taste-skill、mattpocock/skills、addyosmani/agent-skills、graphify、superpowers），Skills 已从"辅助配置"演变为 Agent 能力的核心组织方式。

### 2. 信息获取类 Skill 成为新热点
last30days-skill（跨平台趋势研究）和 graphify（知识图谱构建）的高增长，说明 Agent 对外部信息的获取、整合和理解能力正在成为开发者最关注的能力扩展方向。

### 3. Odysseus 蝉联但增速回归常态
Odysseus 连续两周第一，但本周新增从 2,056 回落至 771，说明爆发期过后进入 steady growth 阶段。即便如此，仍以近 2 倍于第二名的优势领跑。

### 4. Token 优化需求持续
headroom 连续两周 Top 5，Agent 上下文压缩仍是刚需。随着 Agent 任务复杂度提升，Token 成本优化工具的价值愈发凸显。

### 5. 大厂与个人开发者同台竞技
markitdown（微软）、agent-skills（Addy Osmani）、skills（Matt Pocock）与 odysseus、taste-skill 等个人项目同台 Top 10，开源 AI 生态呈现多元化竞争格局。
